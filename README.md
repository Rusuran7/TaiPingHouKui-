# Crypto ETL & Marketing Dashboard

Автоматизированный ETL-пайплайн для сбора и визуализации данных по крипторынку.

## Стек технологий
* **Python** (Extract & Transform)
* **PostgreSQL** (Load/Storage)
* **Power BI** (Visualization)

## Как запустить
1. Склонируйте репозиторий.
2. Создайте базу данных в PostgreSQL, используя `sql/schema.sql`.
3. Настройте ключи доступа в `.env` (используйте `.env.example` как шаблон).
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите `python etl.py`.
